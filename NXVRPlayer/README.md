# NX VR Player

Homebrew-видеоплеер для Nintendo Switch (прошитой, Atmosphère): обычное видео,
стерео-3D фильмы и VR-видео (VR180 / VR360) с отслеживанием головы по гироскопу.
Подходит для картонных VR-очков вроде Nintendo Labo VR.

## Возможности

| Режим (кнопка Y) | Что это | Как смотреть |
|---|---|---|
| **2D** | обычное видео | в руках / на ТВ |
| **3D SBS** | стерео-фильм side-by-side (half и full SBS) | в очках, «экран кинотеатра» |
| **VR180 SBS** | VR180 стерео | в очках, гироскоп |
| **VR360 MONO** | 360° моно | в очках, гироскоп |
| **VR360 TB** | 360° стерео top-bottom | в очках, гироскоп |
| **360 WINDOW** | 360° без очков | крутить консолью или правым стиком |

Режим угадывается по имени файла: `_180`, `_360`, `_tb`/`_ou`, `_sbs`/`_lr`/`3d`.
Например `beach_180_sbs.mp4`, `concert_360_tb.mkv`, `movie.3d.sbs.mkv`.

## Управление

| Кнопка | Действие |
|---|---|
| A | пауза / продолжить |
| ← / → | перемотка −10 / +10 с |
| L / R | перемотка −60 / +60 с |
| Y | сменить режим |
| X | «смотреть прямо» (сброс гироскопа) |
| ZL / ZR (держать) | угол обзора (VR) или размер экрана (3D SBS) |
| ↑ / ↓ | межзрачковое расстояние (в очках) |
| − | коррекция линз вкл/выкл |
| правый стик | осмотреться без гироскопа |
| B | назад к списку файлов |
| + | выход |

## Установка

1. Скопируйте `NXVRPlayer.nro` в `sdmc:/switch/NXVRPlayer/` на карте памяти.
2. Положите видео в `sdmc:/videos/` (можно с подпапками).
3. Запускайте через Homebrew Menu **из игры** (удерживая R при запуске игры),
   а не через Альбом: в режиме апплета мало памяти и FFmpeg может не хватить.

## Сборка

### Вариант 1 — без установки, через GitHub
Залейте папку в свой репозиторий на GitHub. Workflow `.github/workflows/build.yml`
соберёт `NXVRPlayer.nro` автоматически: вкладка **Actions** → последний запуск → **Artifacts**.

### Вариант 2 — локально
1. Установите [devkitPro](https://devkitpro.org/wiki/Getting_Started) (на Windows — установщик с компонентом Switch).
2. Установите библиотеки:
   ```
   dkp-pacman -S switch-pkg-config switch-sdl2 switch-ffmpeg switch-glad switch-mesa
   ```
3. В папке проекта: `make`

## Ограничения и советы

- Декодирование программное (4 ядра Cortex-A57). Плавно: **H.264 до 1920×1080**,
  HEVC 1080p — как повезёт. 4K/5.7K VR-ролики будут тормозить — перекодируйте:
  ```
  ffmpeg -i in.mp4 -vf scale=2560:1280 -c:v libx264 -preset slow -crf 20 -profile:v high -level 4.2 -c:a aac -b:a 160k out_180_sbs.mp4
  ```
  (для 360 моно — `scale=2048:1024`, для 2D — `scale=-2:1080`).
- Экран Switch OLED — 1280×720, на глаз в очках приходится 640×720.
- Если в очках изображение поворачивается не в ту сторону, откройте
  `source/gyro.c` и поменяйте знаки/оси в блоке «Настройка осей».
- Коэффициенты линз (0.22, 0.24) заданы в `source/render.c` (`glUniform2f(u_k, …)`).

## Устройство кода

- `main.c` — главный цикл, управление
- `browser.c` — выбор файла (текстовая консоль)
- `player.c` — FFmpeg (демуксинг, декодирование), звук через SDL2, синхронизация A/V
- `render.c` — OpenGL: YUV→RGB, все проекции и коррекция линз в одном шейдере, экранная панель
- `gyro.c` — отслеживание поворота по гироскопу Joy-Con / Pro Controller
